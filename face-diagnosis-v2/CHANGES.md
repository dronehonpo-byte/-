# v1 → v2 変更点サマリ

既存デモ（`gh-pages` の `index.html`）をベースに、v2 要件と 7/15 クライアント
フィードバックを反映しました。診断ロジック・顔解析エンジンは既存の完成度が高く、
そのまま流用しています。

## 流用した資産（変更なし）
- 顔解析: MediaPipe FaceLandmarker による 15特徴量抽出（`extractFeatures` / `analyzeImage`）
- スコアリング: 決定論の重み付き類似度・動物マッチ・%スプレッド（`PCT_GAIN`）
- 診断結果文: 先方確定版（§5）※既存デモに実装済みのものを踏襲

## 7/15 フィードバック対応状況

| # | 指摘 | 対応 |
|---|---|---|
| 1 | 画像選択後に再度選択UIが出る | `change` を `{once:true}` で紐付け、選択→即診断フローに一本化 |
| 2 | %が50〜65%に集中 | `PCT_GAIN=2.6` で中央基準に拡大。単一%3種は5段階全てに分布（実測: 各端12〜15%） |
| 3 | 再診断できない | 結果画面に「🔄 もう一度診断する」ボタン |
| 4 | 選択画面デザイン | 明るめ背景／「あなたは〇〇！」／メイン画像 約2倍／装飾リフレッシュ |
| 5 | ソース/醤油の表示 | 「ソース顔度 X%」「醤油顔度 Y%」を並列表示 |
| 6 | 課金・広告仕様 | 買い切り¥480＋無料は結果前にリワード広告（モック） |
| 7 | 診断結果文 | §5 の全文を実装（動物10＋各5段階） |

## 検証

- スコアリング/分布/決定論: Node ユニットテスト（4000件の合成顔）で確認
- 二値診断の両側5段階到達性: 6000件で high/low とも全5段階の文言到達を確認
- 画面遷移/描画: Chromium（390×844）で全10画面のスクリーンショット確認・コンソールエラーなし
  （MediaPipe CDN プリロードの通信エラーはサンドボックス起因で、本番/実機では発生しない）

## 既知の制約
- 顔解析エンジンは CDN（jsdelivr / Google Storage）からロード。オフライン初回は失敗し、
  ユーザーフレンドリーなエラー表示＋再試行に誘導。
- 実機確認（iOS Safari / Android Chrome）は要デプロイ後の最終チェック。
