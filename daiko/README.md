# 代行の窓口 — 運転代行マッチングシステム（MVP）

栃木県宇都宮市エリアで、運転代行を **呼びたいお客様** と **対応できる代行業者・ドライバー** を
スマホ上でつなぐマッチングプラットフォーム（PWA / Webアプリ）です。
タクシー配車と異なり「お客様ご本人のお車」を運転するため、**車両情報（車種・MT/AT・ハンドル位置）**
を軸に設計しています。（要件定義書 Ver.2.0 準拠）

## 特徴（コア）

- **料金提示型マッチング**：お客様の1件の依頼に対し、複数ドライバーが「料金＋到着時間」を提示し、
  お客様が見くらべて1名を選択して確定。
- **状態遷移**：募集中 → エントリーあり → 確定 → 対応中 → 完了 ／ キャンセル。
  確定は **「選択した瞬間に1名でロック」** し二重確定を防止（`services/matching.py`）。
- **3つのロール**：お客様 / ドライバー・業者 / 管理者。1つのアプリ内でログインに応じて画面が切替。
- **業者承認**：業者が公安委員会認定書をアップロード → 管理者が承認 → 所属ドライバーが稼働可能。
- **地図・経路**：OpenStreetMap（Leaflet）＋ Nominatim 住所検索 ＋ OSRM ルート案内。
- **電話番号(SMS)認証**：お客様はパスワード不要。SMS は `console`（デモ）/`twilio`（本番）を切替。
- **アプリ内通知**：要件定義書 第10章の通知タイミングを実装（Webプッシュは将来拡張）。
- **PWA**：ホーム画面に追加してアプリのように利用可能。
- **料金は現地精算**（自動決済なし）。キャンセル料は各業者が提示。

## 画面一覧

| ロール | 主な画面 |
|---|---|
| お客様 | 電話番号認証 / ホーム / リクエスト入力 / エントリー待ち・選択 / 確定・連絡先 / ルート案内 / 履歴 |
| ドライバー・業者 | 業者登録（認定書UP） / ログイン / 近くの依頼（一覧・地図） / 詳細・エントリー / 確定案件 / 履歴 |
| 管理者 | ダッシュボード / 利用者一覧 / 業者・ドライバー一覧 / 承認・停止 / マッチング状況・履歴 |

## ローカルで動かす

```bash
cd daiko
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export FLASK_ENV=development DAIKO_SECRET_KEY=dev DAIKO_ADMIN_PASSWORD=adminpass

flask --app wsgi seed          # 管理者 + 参加業者(エンペラー代行) を投入
gunicorn -c gunicorn.conf.py wsgi:app   # http://127.0.0.1:8000
# または: flask --app wsgi run --debug
```

- お客様: `/auth/customer/login`（電話番号 → 画面に表示される認証コードでログイン）
- ドライバー: `/auth/driver/login`（seed が表示したエンペラー代行のログイン情報）
- 管理者: `/auth/admin/login`（admin / adminpass）

## テスト

```bash
pip install pytest
pytest                 # マッチングの状態遷移・二重確定防止・各ロールのフロー
```

## 本番運用前のチェック

- `DAIKO_SECRET_KEY` を本番値に設定。
- SMS を `SMS_BACKEND=twilio` にし、`DAIKO_OTP_SHOW_IN_RESPONSE=false`（コードの画面表示を無効化）。
- 地図/SMS は利用量に応じた実費が発生（花田様名義で契約）。
- 運転代行業は「自動車運転代行業の業務の適正化に関する法律」等の規制対象。参加業者の認定確認・
  法令順守は運営者側の責任範囲（本システムは認定書アップロードと承認機能を提供）。
