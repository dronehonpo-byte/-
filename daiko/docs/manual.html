1. サービス概要

「代行の窓口」は、運転代行を頼みたいお客様と、運転代行業者（ドライバー）をつなぐマッチングサービスです。お客様が出発地・目的地などを送信すると、近くの業者が「料金・到着時間」を提示し、お客様が選んで確定します。

3つの役割ごとにアプリ（画面）が分かれています。

お客様アプリ代行を依頼し、提示の中から選んで確定。連絡先表示・履歴管理。
ドライバー・業者アプリ業者登録、近くの依頼にエントリー（料金提示）、確定後の対応・完了。
管理者アプリ業者の承認・停止・削除、利用者・マッチング状況の管理、データ初期化。

3. スマホでアプリとして使う（ホーム画面に追加）

各URLをスマホのブラウザで開き、ホーム画面に追加すると、通常のアプリのように起動できます。役割ごとに色分けされたアイコンになります。

iPhone（Safari）

  1. Safariで対象URLを開く
  2. 下部の「共有」ボタン → 「ホーム画面に追加」
  3. 「追加」をタップ

Android（Chrome）

  1. Chromeで対象URLを開く
  2. 右上メニュー（︙）→ 「アプリをインストール」または「ホーム画面に追加」

※ 以前に追加した古いアイコンが残っている場合は、一度削除（アンインストール）してから追加し直してください。

4. 通知（プッシュ）の設定

依頼・エントリー・確定・キャンセル・完了などのお知らせを、スマホの通知として受け取れます。

  1. アプリにログイン後、画面下に出る 「🔔 通知をオン」 を押して許可
  2. 画面右上の 🔔 マークの数字は「未読のお知らせ件数」。押すと一覧が開き、既読になり数字が消えます。

※ iPhoneはApple仕様上、「ホーム画面に追加」したアイコンから開いた場合のみ通知を受信できます（iOS 16.4以降）。Android/PCのChromeはブラウザのままでも受信できます。

5. お客様アプリの使い方

  1. ログイン：電話番号を入力 → 表示（またはSMS）される6桁の認証コードを入力。
  2. 依頼する：「代行を依頼する」から、出発地・目的地を地図または住所入力で指定。車種・車名は任意。
  3. ドライバーを選ぶ：各社から届く「料金・到着時間」を見て、希望のドライバーを選んで確定。
  4. 連絡：確定後、担当ドライバーの連絡先が表示されます。電話でやりとりできます。
  5. 完了：ドライバーが対応を完了すると、画面が自動で「対応完了」に変わります。料金は現地精算。
  6. 履歴：過去の依頼は履歴で確認でき、「履歴を削除」で消せます（進行中は不可）。

6. ドライバー・業者アプリの使い方

① 業者登録（初回のみ）

  1. ドライバーアプリ（/driver）→「業者登録」
  2. 業者名・業者電話・代表ドライバー名・ドライバー電話・パスワード（6文字以上）を入力
  3. 対応可能な支払い方法を選択
  4. 公安委員会の認定書（PDFまたは画像）をアップロードして申請
  5. 管理者の承認後に利用開始できます（承認前・停止中はログインできません）

② ログインと依頼対応

  1. ドライバー電話・パスワードでログイン
  2. 近くの依頼一覧から、料金・到着時間を提示して「エントリー」
  3. お客様に選ばれたら確定。お客様の連絡先が表示されます。
  4. 「対応開始（向かう）」→ 到着・送迎 →「対応完了」で終了

7. 管理者アプリの使い方

管理者アプリ（/staff）に、管理者ID・パスワードでログインします。

概況24時間の依頼数・進行中・完了などの状況。各枠を押すと該当一覧へ。
業者の承認業者一覧で、申請中の業者を「承認」。承認後にドライバーがログイン可能に。
業者の停止「停止」を押すと、その業者のドライバーはログイン・受注ができなくなります。
業者の削除「この業者を削除」で、所属ドライバー・提示履歴ごと完全削除。
利用者一覧登録済みのお客様を確認。
マッチング状況各依頼の状態を確認。不要な依頼は「削除」で消去。
データ初期化概況ページ下部の「データ初期化」で、業者・利用者・依頼を全消去（次項参照）。

8. 実運用の始め方（チェックリスト）

  1. データ初期化：（実施済み）テストデータは消去済み。まっさらな状態です。今後もやり直したい場合は、管理アプリ概況ページ下部「データ初期化」で確認欄に リセット と入力して実行。
  2. 実際の代行業者を登録：各業者にドライバーアプリ（/driver）から業者登録してもらう。
  3. 管理者が承認：管理アプリの業者一覧で内容・認定書を確認し「承認」。
  4. お客様へ告知：お客様用URL・QRを配布。

9. 一般公開の前に（重要）

すぐにパイロット運用できる状態ですが、不特定多数へ本格公開する前に、以下2点の切り替えを推奨します（別途対応可能です）。

  • SMS認証の実送信化：現在はテスト用に認証コードを画面表示しています。実際の一般公開では、Twilio連携でSMSを実送信する設定に切り替えると安全です。
  • データベースの本番プラン化：現在は無料枠（30日期限）です。継続運用の前に有料プラン（月約$7）への切り替えを推奨します。

よくある質問

  • ドライバーがログインできない：管理者が「承認」しているか、業者が「停止」になっていないかご確認ください。
  • 依頼に誰も反応しない：承認済みの代行業者（ドライバー）が登録されているかご確認ください。
  • 画面が古いまま：ブラウザの再読み込み、またはアプリを一度閉じて開き直してください。

その他ご不明点・追加のご要望は、開発担当までお問い合わせください。
