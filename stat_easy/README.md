# StatEasy — Excel/CSV 対応 自動統計解析ツール

> 統計の面白さを、手法名を知らなくても。
>
> 研究目的を選ぶだけで、最適な統計手法が自動で選ばれ、論文・レポートにそのまま使える
> 図表（APA 形式の表 / 300dpi PNG・SVG 図）を出力します。

**開発：土居拓務・株式会社Miyabee**

---

## 特長

- **手法名を知らなくても使える**：「群の違いを調べたい」を選ぶだけで、正規性検定（Shapiro-Wilk）・
  等分散性検定（Levene）を踏まえて t 検定 / Mann-Whitney U 検定 / ANOVA / Kruskal-Wallis 等を**自動選択**します。
- **なぜこの検定？を必ず表示**：教育目的のため、選択理由を毎回わかりやすく説明します。
- **生成 AI は統計計算に一切使いません**：計算はすべて SciPy / statsmodels / scikit-learn / pandas / NumPy で行い、
  「同じデータ・同じ設定 → 常に同じ結果」という再現性を担保しています。
- **論文クオリティの出力**：APA 形式（三線表）の表を Excel / Word / PDF で、図を PNG（300dpi）と SVG（ベクター）で出力できます。
- **完全ローカル実行**：インターネット接続不要。Windows 10/11 で動作します。

## 搭載する機能（7 つ）

| # | 機能 | 内容 |
|---|------|------|
| ① | データ品質診断 | 型判定 / 欠損値レポート / 外れ値（IQR・Z-score）/ 重複行 / 有効 N |
| ② | 記述統計・Table 1 | 連続・カテゴリ変数の要約、群別比較表（APA 形式）|
| ③ | 仮説検定の自動選択 | 群数・正規性・対応・期待度数から最適な検定を自動選択 |
| ④ | 効果量・信頼区間 | Cohen's d / Hedges' g / η² / Cramer's V、95%CI（bootstrap 可）|
| ⑤ | 相関・回帰分析 | 相関行列、線形回帰（VIF・残差診断）、ロジスティック回帰（オッズ比・ROC）|
| ⑥ | クラスタリング | k-means（Elbow・シルエット）/ 階層的（デンドログラム）/ PCA 散布図 |
| ⑦ | 図表出力 | ヒストグラム・箱ひげ図・散布図・ヒートマップ等を PNG/SVG で出力 |

> ※ 「予測モデルを作る（機械学習比較）」は、単体でも高度なアプリに相当するため
> 本アプリの対象から外しています（依頼者ご要望による）。

## セットアップ手順（Windows 10/11）

### 1. Python を用意する

[python.org](https://www.python.org/) から **Python 3.10 以上** をインストールしてください。
インストール時に「**Add Python to PATH**」にチェックを入れてください。

### 2. セットアップ（初回のみ）

`stat_easy` フォルダを開き、**`setup.bat` をダブルクリック**します。

- 仮想環境 `venv` が作られ、必要なパッケージが自動でインストールされます（数分かかります）。
- 「セットアップ完了！」と表示されたら成功です。

> コマンドプロンプトから実行する場合：
> ```bat
> cd stat_easy
> setup.bat
> ```

### 3. 起動する

**`run.bat` をダブルクリック**します。自動的にブラウザが開き、StatEasy の画面が表示されます。

> 自動で開かない場合は、ブラウザで http://localhost:8501 にアクセスしてください。
> 終了するには、コマンドプロンプトのウィンドウを閉じてください。

## 使い方（3 ステップ）

1. **データを読み込む** … 「データアップロード」から CSV / Excel(.xlsx) を読み込みます（文字コードは自動判定）。
   まずは付属のサンプルデータで試せます。
2. **目的のメニューを選ぶ** … 左サイドバーの「データを確認したい」「群の違いを調べたい」
   「変数間の関係を調べたい」「グループに分けたい」「図表を出力する」から選びます。
3. **結果を解釈・出力する** … 画面上で結果と解説を確認し、表（Excel/Word/PDF）や図（PNG/SVG）をダウンロードします。

## サンプルデータ

`sample_data/` に 2 種類を同梱しています（欠損・外れ値を意図的に混入）。

- `sample_experiment.csv` … 介入群/対照群の実験データ（t 検定・効果量・Table 1 向け）
- `sample_survey.csv` … リッカート尺度のアンケート（記述統計・クロス集計・カイ二乗向け）

サンプルを再生成したい場合：
```bat
python sample_data\_generate.py
```

## 開発者向け

### ディレクトリ構成

```
stat_easy/
├── app.py              # 起動エントリーポイント（サイドバー・ナビゲーション）
├── requirements.txt
├── setup.bat / run.bat
├── .streamlit/config.toml   # カラーテーマ
├── modules/            # 統計計算（① 〜 ⑧）
├── exporters/          # Excel / Word / PDF 出力
├── pages/              # 各画面
├── sample_data/        # サンプル CSV
├── assets/style.css
└── tests/              # pytest
```

### テスト

```bat
python -m pytest
```

主要関数の単体テスト（`tests/test_core.py`）と、全ページの統合スモークテスト
（`tests/test_pages.py`）が含まれます。

### 設計上の約束

- 統計計算に生成 AI を使用しない（OpenAI API 等の呼び出し禁止）。再現性を最優先します。
- 図の日本語が文字化けしないよう、日本語フォント IPAexGothic（`assets/fonts/ipaexg.ttf`）をアプリに同梱して使用します。
- APA 形式の表は三線表（上下に太線、ヘッダー下に細線）を基本スタイルとします。
