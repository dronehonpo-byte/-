# SEMEasy — 共分散構造分析（SEM）支援ツール

> データを読み込み、モデルを作り、推定し、結果を確認・出力するまでを
> 5つの手順に沿って進められるアプリです。

**開発：株式会社Miyabee**

---

## 1. このアプリの考え方

- **計算に生成 AI を使いません。** 推定は検証済みの SEM ライブラリ（semopy）と
  NumPy / SciPy のみで行います。同じデータ・同じ設定・同じ乱数シードであれば、
  **常に同じ結果**が得られます（再現性）。
- **画面ごとに数値がズレません。** 1回の推定結果（単一の計算結果）から、
  画面表示・パス図・数値表・レポート・再現コードの**すべて**を生成しています。
- **「正解」を断定しません。** 適合度が良いことは、そのモデルが唯一正しいことや、
  変数間に因果関係があることを証明しません。本アプリは「数値上あてはまりの良い候補」を
  示すもので、理論的な正しさは利用者がご判断ください。
- **アップロードしたデータを外部に送信しません。** すべてお使いのパソコン内で処理されます。

## 2. セットアップ（Windows）

### 2-1. Python を用意する
[python.org](https://www.python.org/) から **Python 3.10 以上** をインストールします。
インストール時に「**Add Python to PATH**」にチェックを入れてください。

### 2-2. セットアップ（初回のみ）
`setup.bat` をダブルクリックします。仮想環境が作られ、必要な部品が自動で入ります（数分）。

### 2-3. 起動
`run.bat` をダブルクリックします。ブラウザが開き、ログイン画面が表示されます。

## 3. ログイン（ID・パスワード）

初期アカウントは以下のとおりです。**運用開始前に必ずパスワードを変更してください。**

| ID | 初期パスワード | 用途 |
|---|---|---|
| `doi` | `SEM0703` | 通常利用 |
| `miyabee` | `Miyabee2026` | 管理用 |

### パスワードの変更・利用者の追加
コマンドプロンプトで `sem_easy` フォルダに移動し、次を実行します。

```bat
venv\Scripts\activate

REM パスワードの変更
python manage_users.py passwd doi 新しいパスワード

REM 利用者の追加（表示名・利用期限は任意）
python manage_users.py add student1 パスワード "ゼミ生1" 2027-03-31

REM 一覧・削除
python manage_users.py list
python manage_users.py delete student1
```

### 認証の仕様
- パスワードは **平文で保存しません**（PBKDF2-HMAC-SHA256／利用者ごとの salt 付き）
- **5回**連続で失敗すると **15分間**ロックされます
- セッションは **8時間**で期限切れになります（ログアウトも可能）
- 利用者ごとにデータを分離して保持します
- アカウントに**利用期限**を設定できます

| 手順 | 画面 | 内容 |

| ① | データ読込 | Excel / CSV の個票データ、相関行列、共分散行列を読み込みます |

## 6. 結果の読み方（かんたんな解説）

### 6-1. 適合度指標
モデルがデータとどの程度整合しているかの目安です。**一つの数値で良し悪しを決めません。**

| 指標 | 見方 | 一般的な目安 |
|---|---|---|
| χ²（p値） | ズレが統計的に有意か | 標本が大きいと有意になりやすく、この検定だけでは判断しません |
| CFI / TLI | 1に近いほどあてはまりが良い | 0.95以上が目安、0.90以上で境界的 |
| RMSEA | 小さいほど良い（信頼区間も確認） | 0.06以下が目安、0.08以下で境界的 |
| SRMR | 小さいほど良い | 0.08以下が目安 |
| AIC / BIC | モデル間の比較に使う（小さい方が良い） | 単独では意味を持ちません |

本アプリは「良好」と断定せず、**「目安を満たしている／境界的である／目安を満たしていない／
指標によって判断が分かれている」**と表示します。

### 6-2. 係数
- **非標準化係数**：もとの単位のままの係数
- **標準化係数**：単位をそろえた係数（変数間で大きさを比べたいとき）
- **標準誤差・z値・p値・95%信頼区間**：推定のばらつきと統計的な有意性
- **R²**：その変数がどの程度説明できたか

### 6-3. 直接効果・間接効果・総効果（媒介分析）
- **直接効果**：X から Y への直接の矢印の係数
- **間接効果**：経路上の係数の**積**（例：X→M が 0.50、M→Y が 0.40 なら 0.50×0.40＝0.20）
- **総効果**：直接効果＋間接効果

本アプリは「どの係数を掛け合わせたか」を表示するため、手元で検算できます。

### 6-4. 診断（3段階）
「計算が終わったこと」と「研究上問題のない結果が得られたこと」は別です。

1. **モデルを計算できる形になっているか**（定義の問題）
2. **計算が正常に終了したか**（収束）
3. **得られた数値に不自然な点がないか**（負の分散、標準化係数が1超、相関が1に近い 等）

### 6-5. パス図の見方
- **楕円**＝潜在変数（目に見えない構成概念）、**長方形**＝観測変数（実際の質問項目）
- 測定モデルの矢印は「**潜在変数 → 観測変数**」の向きです
  （自己効力感という性質が、各項目への回答に表れる、という考え方）

## 8. 動作確認（テスト）

```bat
venv\Scripts\activate
python -m pytest
```

含まれる主な検証：

- **推定の正確性**：パス解析の推定値が OLS 回帰の結果と一致すること
- **画面・数値表・レポート・再現コードの数値が完全に一致すること**
- 間接効果が経路上の係数の積と一致し、総効果＝直接＋間接であること
- モデル名が実際のパス構成と一致すること（名前と図が食い違わない）
- 測定モデルの矢印が「潜在→観測」であること
- 適合度の判定が「良好」と断定しないこと
- 使えない推定法と欠損処理の組合せが選べないこと
- パス図に日本語の文字化け（豆腐）が出ないこと
- 同じ設定なら常に同じ結果になること（再現性）
- 認証：平文保存なし・ロック・利用期限・利用者ごとのデータ分離

## 9. 初期版の対応範囲と、今後の拡張候補

### 対応済み（初期版）
確認的因子分析（CFA）、パス解析、媒介を含む SEM、候補モデルの自動生成と比較、
相関・共分散行列の入力、順序尺度への対応（DWLS）、欠損への対応（FIML）、
パス図、各種出力、再現コード、ID・パスワード認証。

### 今後の拡張候補（第2段階）
多母集団同時分析、測定不変性の検証、潜在交互作用、縦断 SEM、ベイズ SEM、
SPSS（.sav）の読み込み、プロジェクトの保存・変更履歴の永続化。

## 10. 技術メモ

- 推定エンジン：semopy（Python）
- 適合度指標：CFI・TLI・RMSEA（信頼区間・p-close）・SRMR・AIC・BIC を
  `modules/fitindices.py` で一元的に計算（画面ごとの再計算を行わないため数値がズレません）
- 日本語フォント：IPAexGothic を同梱（`assets/fonts/ipaexg.ttf`）
