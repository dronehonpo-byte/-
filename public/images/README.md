# 役員写真の配置

このディレクトリに以下のファイルを配置してください。**画像と人物の対応に注意**：

| ファイル名 | 配置すべき画像 | 該当人物 |
|---|---|---|
| `ceo.jpg` | **後ろ姿のスーツ写真** | CEO Masaki |
| `cso.jpg` | **正面・腕組みのスーツ写真（顔がある方）** | CSO 椿海生 |

サイズ目安：縦横比 4:5、解像度 1200×1500px 以上を推奨。

## フォールバック挙動

ファイル未配置時は `components/sections/leadership.tsx` の `Portrait` 内
`onError` ハンドラが発火し、グラデーション + イニシャル（M / K）+ "Photo
coming soon" バッジの CSS プレースホルダーが代わりに表示されます。
ビルドは失敗しません。
